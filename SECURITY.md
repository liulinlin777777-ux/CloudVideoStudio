# Security Policy

## Project status

CloudVideoStudio is at the planning and repository bootstrap stage. No application code or supported product releases are available yet.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities, exploit details, credentials, or private data in a public Issue or Discussion.

When available, use GitHub's **Report a vulnerability** action in this repository's Security tab to send a private report. If private vulnerability reporting is unavailable, contact a maintainer privately through GitHub and ask for a secure reporting route. Do not include secrets in that request.

There is no response-time commitment while the project is being established. Please allow maintainers time to assess a report before disclosing it publicly.

## Contributor security requirements

- Never commit API keys, tokens, passwords, private certificates, or cloud/server access details.
- Do not submit video, image, audio, or other material unless it is authorized for public distribution.
- Do not upload source code from another project without the right to redistribute it.
- Review dependency licenses and security notices before proposing a dependency.
- Treat all external Pull Request content as untrusted. Workflows must use explicit least-privilege permissions, must not expose production or deployment credentials to untrusted contributions, and must not run deploy or release actions for fork Pull Requests.
